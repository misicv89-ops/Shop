# Čilibar – Srebrni Nakit

Online prodavnica (jedna stranica `index.html`).

## Objava na GitHub Pages
1. Napravite novi repozitorijum na github.com (npr. `cilibar-shop`), javni.
2. **Add file → Upload files** → prevucite `index.html`, `.nojekyll` i ovaj `README.md` → **Commit changes**.
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → **Save**.
4. Za 1–2 minuta sajt je na: `https://VAŠE-IME.github.io/cilibar-shop/`
